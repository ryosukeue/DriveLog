# Vision

## プロダクト概要

iPhoneの低消費電力な位置情報監視を利用し、ユーザーが操作しなくても移動履歴が自動的に蓄積され、日付ごとに移動経路・移動距離・滞在地点・写真・動画を振り返れるアプリを作る。

単なるGPSロガーではなく、「その日にどこへ移動し、どこに滞在し、どんな写真や動画を撮ったか」をカレンダーと地図から直感的に思い出せる移動日記を目指す。

## 提供価値

ユーザーは記録開始・停止を毎回操作する必要がない。

アプリを開くと、カレンダー上から移動した日を確認でき、日付を選択すると、その日の移動経路、移動時間、距離、滞在地点、写真・動画をまとめて振り返れる。

位置情報、写真、動画、分類結果は端末内で処理し、外部サーバーへ送信しない。低消費電力、プライバシー、操作不要を優先する。

## MVPの目的

MVPでは、OwnTracksのSignificant Location Changeモードに近い低消費電力な移動記録を再現する。

最優先で実現する状態は次のとおり。

- 一度権限を許可すると、大きな位置変化が自動で記録される
- 移動した日がカレンダー上で分かる
- 日付を選ぶと、その日の移動経路と写真・動画を確認できる
- 移動区間、移動距離、移動時間、区間ごとの推定平均速度、推定滞在地点を確認できる
- 車両系移動、徒歩系移動、その他を大まかに区別できる
- 不要な日付の移動ログをユーザーが削除できる

## 基本原則

- iPhone専用とする
- ユーザー操作を極力必要としない
- 高精度GPSの連続追跡を行わない
- Significant Location Changeを中心に電池消費を抑える
- 位置情報、写真、動画、分類結果は端末内で完結させる
- 写真や動画を複製せず、Apple Photosライブラリを参照する
- 分類結果、経路、速度、滞在時間は推定値として扱う
- 完全な精度より、長時間継続して自然に記録されることを優先する
- MVPでは機能を絞り、将来拡張できる構造を前提とする
