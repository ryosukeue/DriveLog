# DriveLog Support（公開前の下書き）

問い合わせ先: `[要入力]`

## DriveLogについて

DriveLogは、iPhone上で移動履歴を記録し、日付ごとの経路、滞在、写真・動画を振り返るアプリです。

## 初回設定

1. 位置情報の利用を許可します。
2. バックグラウンド記録を使う場合は、iOS設定で位置情報を「常に」にします。
3. モーションと写真の利用を許可します。
4. アプリを通常どおり使用し、後からカレンダーで記録を確認します。

## 記録されない場合

- 位置情報が許可されているか確認してください。
- モーション権限が制限されていないか確認してください。
- iOSの省電力制御やバックグラウンド制限により、記録が遅れる場合があります。
- 処理完了まで、地図や集計の表示に時間がかかる場合があります。

## 写真が表示されない場合

写真ライブラリの権限、写真の撮影日時、写真に位置情報が付いているかを確認してください。位置情報のない写真はギャラリーには残りますが、地図上には表示されません。

## データ削除

カレンダーから対象日を開き、日付削除を実行してください。DriveLogの記録は削除されますが、Apple Photosの元写真・動画は削除されません。

## 既知の制限

- GPS環境が悪い場所では経路が粗くなる場合があります。
- iOSの制約により、バックグラウンドで正確な周期記録は保証されません。
- アプリを強制終了した場合、記録の自動再開は保証されません。

## 問い合わせ時に伝えてほしいこと

- iPhone機種とiOSバージョン
- DriveLogのバージョン
- 発生日時と対象日
- 権限設定の状態
- 問題の概要

位置情報、写真の識別子、写真そのものをメールへ添付しないでください。
