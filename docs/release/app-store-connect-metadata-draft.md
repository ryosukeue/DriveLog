## Description（下書き）

DriveLogは、iPhoneの位置情報を使って移動履歴を記録し、日付ごとに経路、滞在、写真・動画を振り返るアプリです。

記録したデータは端末上で処理します。移動日の写真・動画は、位置情報がある場合に地図上へ表示できます。写真・動画の元データをDriveLogのサーバーへ送信する機能はありません。

GPS環境やiOSのバックグラウンド制約により、記録の間隔や経路表示に欠損・遅延が生じる場合があります。安全運転の補助や証拠用途を目的とするものではありません。
